Chat Widget Test Page

This page is for testing the chat widget functionality. The chat widget should appear in the bottom-right corner.

Test Scenarios

  • Basic Chat: Click the chat button and send a message
  • Reservation Flow: Send a message containing "sofa", "book", or "appointment" to trigger the reservation flow
  • Calendar: Test date selection (weekends should be hidden, 5 days per row)
  • Time Slots: Test time slot selection (some slots should be pre-picked in gray/orange, selected in yellow)
  • User Details Form: Fill out and submit the reservation form
  • Back Button: Test navigation back through the flow steps

Test Messages

Try sending these messages to test different scenarios:

  • "I want to see the sofa"
  • "Book an appointment"
  • "Can I reserve a time?"
  • "Hello" (for general chat)

Instructions

To use this test file:

  1. Make sure you've run npm run build to build the project
  2. Serve this HTML file using a local server (e.g., python -m http.server or npx serve)
  3. Open the served URL in your browser
  4. The chat widget should appear in the bottom-right corner
